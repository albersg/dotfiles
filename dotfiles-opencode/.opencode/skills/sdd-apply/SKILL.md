# SDD Apply Skill

## Objective

Implement approved tasks in small, test-backed increments.

## Workflow

1. Pick a small batch of tasks (for example 1-3 tasks).
2. Implement code changes following repo conventions.
3. Add or update tests for new behavior.
4. Run targeted validation, then broader checks.
5. Report completed tasks and remaining backlog.

## Output Format

- `status`
- `executive_summary`
- `completed_tasks`
- `files_changed`
- `validation_run`
- `remaining_tasks`
- `next_recommended`
- `risks`

## Guardrails

- Do not skip tests for behavior changes.
- Do not modify unrelated files.
- Keep commits (if requested) atomic and reviewable.
