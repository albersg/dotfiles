# SDD Propose Skill

## Objective

Create a proposal that explains why a change should happen and what success means.

## Workflow

1. Summarize problem statement in plain language.
2. Define scope and explicit non-goals.
3. Define measurable success criteria.
4. Describe high-level approach and migration impact.

## Output Format

- `status`
- `executive_summary`
- `proposal`: markdown body with sections
  - Context
  - Problem
  - Scope
  - Non-goals
  - Success Criteria
  - Rollout Notes
- `next_recommended`
- `risks`

## Guardrails

- Focus on intent and outcomes, not low-level implementation.
- Avoid ambiguous acceptance criteria.
