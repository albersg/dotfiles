# Utilities refresh: what the section gets wrong, and what it is missing

The installer's Utilities section ships four jobs today -- the system theme switch, the
dotfiles theme switch, the WSL resources, the shell's startup measurement and the terminal
capability report -- and none of them has been read as a whole since it landed. This front
reads all of them, fixes what is actually broken, and adds the job the section was missing.

Work happens in a dedicated worktree (`dotfiles-utilities`, branch `feat/utilities-refresh`)
because other sessions are writing to the same clone.
